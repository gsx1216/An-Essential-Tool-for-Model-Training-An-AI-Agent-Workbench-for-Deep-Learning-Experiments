# 登录业务串联练习

`app/services/login_service.py` 中的 `LoginService.login()` 已完成，下面保留调用顺序与验收清单供回顾。现在 `/auth/login` 返回 Token、有效秒数和公开用户信息；已有 Token 的校验也已接入 `/auth/me`，完整关系见 `docs/注册登录完整流程说明.md`。

## 本次调用顺序

```text
LoginService.login(username, password)
    → AuthService.authenticate：验证账号密码，返回用户 ID 和规范用户名
    → TokenService.create_token：创建原始凭证
    → TokenService.hash_token：计算存库用的哈希
    → TokenService.get_expires_at：计算三天后的 UTC 到期时间
    → LoginSessionRepository.save_session：保存所属用户、哈希和到期时间
    → LoginResult：提交成功后返回原始凭证和公开用户信息
```

身份来自密码核对结果，不能让前端自行传入要登录的 `user_id`。保存失败时，异常继续向上传递，本次登录不能返回成功结果。

## 三个对象如何配合

构造函数已经提供三个属性。它们保存的是可调用的协作者，不是继承关系：

| 属性 | 职责 |
|---|---|
| `self.auth_service` | 验证用户名和密码 |
| `self.token_service` | 创建凭证、计算哈希、计算到期时间 |
| `self.session_repository` | 通过参数化 SQL 保存登录记录并提交事务 |

这三个对象都可以在多次请求中复用。本次请求的用户名、密码和原始 Token 要作为方法局部变量使用。

## await 放在哪里

| 调用 | 写法 |
|---|---|
| `AuthService.authenticate` | 它是 `async def`，使用 `await` |
| Token 工具的三个方法 | 普通同步计算，直接调用 |
| `LoginSessionRepository.save_session` | 它是同步数据库操作，通过 `await asyncio.to_thread(函数, 参数...)` 调用 |

`to_thread` 第一个参数传函数本身，例如 `self.session_repository.save_session`；直接加括号会先在当前线程执行数据库操作。

## LoginResult 是什么

`app/models/login_result.py` 已实现，负责装载业务结果。你可以把它理解为一个字段固定的数据对象。用关键字参数创建：

```python
LoginResult(
    access_token=...,  # TODO：填写对应变量
    expires_in=...,   # TODO：填写 Token 的有效秒数
    user_id=...,      # TODO：填写已经验证的用户编号
    username=...,     # TODO：填写验证返回的用户名
)
```

`token_type` 默认是 `"bearer"`；`expires_in` 应为 `259200` 秒，由 TokenService 的配置提供，不在登录方法里重复硬编码。

这个对象属于业务层；已有的 `LoginResponse` 属于 HTTP 层。路由把业务结果转成响应。`LoginResult` 的默认调试表示隐藏 Token，但完整字段仍包含原始凭证，不能写进日志。

## 写完后要验证的场景

| 场景 | 预期 |
|---|---|
| 正确密码、保存成功 | 返回原始 Token、三天有效期和已验证用户信息 |
| 密码错误或用户不存在 | 抛出原有认证异常，不生成或保存凭证 |
| 同一用户重复登录 | 每次生成新的随机凭证 |
| 数据库插入或提交失败 | 异常继续抛出，本次不返回成功结果 |
| 保存内容 | 只传入验证后的用户 ID、Token 哈希和带时区的到期时间 |
| 模拟数据库阻塞 | 通过 `to_thread` 调用，其他异步任务仍可继续 |
| 日志 | 能关联操作与失败，不含密码、Token 或完整返回内容 |

业务服务和 HTTP 入口分别有对应的单元测试与临时 MySQL 联调。Swagger 手工操作见 `docs/Swagger登录验证.md`。账号密码拒绝由 `InvalidCredentialsError` 表示，路由返回 401；凭证计算或保存中的程序异常继续交给全局处理，不会被误报为密码错误。
