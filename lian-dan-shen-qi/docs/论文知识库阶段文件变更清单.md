# 论文知识库阶段：文件变更与验证

日期：2026-10-28。以下全部路径相对于 `E:\code\LangChian_New`。

新增 **31** 个文件、修改 **25** 个文件、删除 **0** 个文件。没有修改实际 `config/.env`，没有新增 Redis Stream、向量服务或常驻 Worker。唯一新增依赖为 **pypdf==6.21.3**，安装在指定 langchain 环境。新增 papers / paper_files / paper_chunks；当前39张共享业务表、64条路径、80个HTTP操作。

本阶段完成本人 PDF 原件保存、按页提取分块、MySQL ngram 关键词检索、聊天与独立建议 Agent 的实际页码/引文证据，以及失败重试和级联删除。论文库属于用户，不依附具体聊天。并不是向量语义检索或扫描件 OCR。

## 验证记录

- 全量单元测试 **1,276项通过**，包含新增论文专项23项。
- 新增真实 MySQL/HTTP/PDF 联调 **14组通过**：真实 Windows pypdf 子进程、真实 ngram 索引、上传原件比对、用户隔离、幂等/过期恢复、原子回滚、私有资料外发工具隔离、实际引文、建议及删除。
- 原有公开研究 **11组**、独立建议 **11组**、对话训练 **10组**回归通过；训练回归仅本机回环 SSH 三次微型 CPU 作业。
- 增量建表可重复执行，临时库验证39张表；OpenAPI 已导出64路径/80操作。
- 本机 MySQL max_allowed_packet=64 MiB、ngram_token_size=2；未修改全局配置。

模型、公开网页和论文联调中的 SSH 均为替身；没有真实供应商用量或真实 GPU 训练。本阶段没有重跑完整 Redis 通信测试、真实 Linux PDF 解析或生产部署压测，不能把单元/替身验证当作这些项目已验收。

安装使用本清单逐个核对原文件，遇到用户并发修改停止覆盖。仅复制本阶段变更，不删除旧文件。原件/分块采用共享 MySQL 表；删除论文不追溯清除已经保存的聊天/建议证据快照。
