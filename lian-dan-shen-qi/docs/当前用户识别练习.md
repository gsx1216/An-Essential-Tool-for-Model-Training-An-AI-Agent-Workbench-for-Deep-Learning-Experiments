# 当前用户识别练习

上一阶段完成账号密码登录和凭证签发。这一阶段识别请求携带的已有 Token 属于谁，最终会用于 `GET /auth/me` 和其他需要登录的接口。

当前状态：`CurrentUserService.get_current_user()` 与 `/auth/me` 的 HTTP 接入均已完成，并通过单元测试和真实临时 MySQL 联调。下文保留业务层练习供回顾；完整调用关系见 `docs/注册登录完整流程说明.md`，新任务见 `docs/退出登录练习.md`。

## 这次先写哪里

本练习是在 `app/services/current_user_service.py` 中实现 `CurrentUserService.get_current_user()`。构造函数、异常、查询 SQL 和仓储方法由基础设施层提供，业务方法决定校验和调用顺序。

开发顺序是先检查业务方法，再接入 Bearer 请求头依赖、`GET /auth/me` 及 Swagger 的 Authorize 按钮。当前这些步骤均已完成。

接入时会结合实际代码解释三层关系：`@router.get` 声明路径和请求方法，`Depends` 提取凭证并调用业务校验，`app.include_router` 将路由注册到 FastAPI 应用。服务方法本身不会自动变成 HTTP 接口。

## 数据如何流动

```text
原始 access_token
  → 检查格式
  → 计算 token_hash
  → 在工作线程中调用仓储
      → 查询 login_sessions，并关联 users
      → 要求未到期、未撤销
  → 查不到：抛出 InvalidTokenError
  → 查到：返回 (user_id, username)
```

身份只来自查询结果。用户无需重新输入密码，也不应传一个 user_id 来指定自己是谁。后续 HTTP 请求格式为 `Authorization: Bearer <access_token>`；传给本方法的参数只包含 Token 本身，不包含前面的 `Bearer `。

## 已有方法怎样使用

| 对象或方法 | 输入 | 输出 | 调用方式 |
|---|---|---|---|
| `self.token_service.hash_token` | 原始 Token | 64 位哈希字符串 | 普通调用 |
| `self.session_repository.get_active_user` | Token 哈希 | `(用户 ID, 用户名)` 或 `None` | `await asyncio.to_thread(...)` |
| `InvalidTokenError` | 统一错误提示 | 抛出业务异常 | `raise` |

`get_active_user()` 的 SQL 已核对 `revoked_at IS NULL`、`expires_at > UTC_TIMESTAMP(6)`，并关联用户表。不用再查询一遍用户是否存在。

Token 格式符合只表示它像一个签发过的 Token。只有数据库查到仍有效的对应记录，才算通过验证。不要在这个方法里生成新 Token、保存登录记录或延长到期时间。

`asyncio`、`re` 以及业务异常等导入已提供，填写 TODO 后会用到。末尾的 `NotImplementedError` 用于明确阻止未完成的功能放行，全部填好后删除。

## 填完后如何验收

| 场景 | 应有结果 |
|---|---|
| 已保存且未到期、未撤销的 Token | 返回其所属用户的信息 |
| 格式正确但数据库不存在的 Token | 抛出 `InvalidTokenError` |
| 空字符串、格式错误、缺少字符 | 抛出 `InvalidTokenError`，不查询数据库 |
| 已过期或已撤销的 Token | 抛出 `InvalidTokenError` |
| 不同用户各自的 Token | 分别返回各自的身份 |
| 数据库故障 | 原异常继续抛出，不冒充凭证无效 |
| 多次验证同一个有效 Token | 不创建新记录，不延长有效期 |

数据库故障后续由 HTTP 层转换为 503 和“请稍后重试。”；无效凭证转换为 401。这次业务服务不需要导入 `HTTPException`。日志装饰器已接好，不要打印原始 Token 或将其写入异常消息。

仓储和业务都有模拟测试，独立临时 MySQL 验证脚本 `scripts/verify_current_user_mysql.py` 覆盖业务方法；`scripts/verify_current_user_api_mysql.py` 覆盖 HTTP 接入，包括无效凭证拒绝与真实数据库异常响应。现在可以在 Swagger 中测试 `/auth/me`。
