## 这次依赖为什么只提取 Token

`get_bearer_token()` 提取当前请求中的原始 Token。LogoutService 自己校验格式，并用一条带条件的 UPDATE 检查有效性和撤销记录，因此不再加 `Depends(require_current_user)` 先查询一次用户。

退出目标由 Token 决定，不接收客户端提供的 user_id 或登录记录 ID。缓存工厂只复用服务对象；每次请求都必须调用 logout，不能缓存退出结果。

## 填好后如何验收

已补充 `tests/test_logout_api.py`，验证成功、重复退出、无效凭证、错误响应和服务工厂。`scripts/verify_current_user_api_mysql.py` 已覆盖真实 HTTP 退出及数据库撤销，不再只调用 LogoutService。

接口检查通过后，在 `/docs` 中验证：

1. 调用 `/auth/login`，复制实际返回的 access_token。
2. 点击 Authorize，只粘贴 Token 本身。
3. 调用 `/auth/me`，确认 200。
4. 调用 `POST /auth/logout`，应为 204，Response body 为空。
5. 保留相同 Token，再调用 `/auth/me`，应为 401。
6. 再次调用 `/auth/logout`，应为 401。

还要验证同一账号另一条登录记录、其他账号登录均不受影响；数据库故障返回 503，响应只提示“请稍后重试。”，日志通过 X-Request-ID 定位。

Swagger 授权窗口中的 Logout 只清除文档保存的输入。这里的 `/auth/logout` 才会请求服务器撤销数据库中的凭证。
