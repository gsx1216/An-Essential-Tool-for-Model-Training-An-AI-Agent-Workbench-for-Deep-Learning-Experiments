## 验证

- 通用项目专项测试：25 项。包含配置与归属、Agent 读项目、不同目录和不同参数名的两个项目、实际本机 CPU 梯度下降、指标与产物、退出码、入口变更、修改副本与重复启动。
- 关联专项检查：97 项通过。
- 完整回归：1292 项通过（36.429 秒）。
- 本机 Windows CPU 子进程验收不等同于新的 Linux SSH / GPU 实验；本次没有连接真实训练服务器或调用收费模型。
- OpenAPI 由实际路由导出：69 条路径、85 个 HTTP 操作。

## 更新后如何使用

重启 API 与相关 Worker，重新创建自己的 project 任务。已有旧专用任务不自动变成通用任务；按真实训练入口核对环境、参数、输出和指标后保存新配置。

详细步骤见 [通用训练项目接入与接口说明](通用训练项目接入与接口说明.md)。
