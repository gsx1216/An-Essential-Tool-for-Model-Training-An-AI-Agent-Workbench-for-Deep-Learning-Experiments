### 1. 基础联通与身份

1. 启动后端 8000 和前端 5173，打开前端页面。
2. 注册一个测试账号；重复用户名应显示后端的明确提示。
3. 错误密码登录不应进入工作台；正确密码登录后显示当前用户。
4. 刷新浏览器，应恢复当前登录和会话列表。退出登录后，受保护页面应回到登录页。
5. 另一个账号登录后，不应看到前一个账号的会话或服务器。

### 2. 模型 Key 与聊天

1. 在“设置”保存你自己的有效 Key。原 Key 不会被页面回显。
2. 点“新聊天”，输入普通问题。正常收到回复后刷新页面，确认历史还在。
3. 选择一个已部署 Skill，再发送新问题；在工具记录的轮次入口核对 Skill 快照。
4. 仅讨论“如何训练”“最近训练结果”时，不应自动开始新训练。
5. 人为断网测试时，页面应提示结果不明，点“重试本轮”沿用原编号；不要通过新问题重复授权同一个训练。
6. 切换不同会话，确认历史和回复没有串入其他会话。
7. 删除一个可丢弃的测试会话，确认该会话及内容不可再访问；原来已运行的训练不会因此停止。

真实聊天会使用你自己的模型服务配额。本轮自动验收没有执行这一步的付费调用。

### 3. 服务器和训练

1. 添加一个自己的服务器；密码模式不填私钥，私钥模式不填登录密码。主机指纹仍需填写。
2. 点击测试连接。连接成功应显示指纹验证结果与时间，失败显示安全提示。
3. 新建 training 实验，按实际方向填写评测协议、数据集与指标。
4. 配置一个对话训练任务；保存后服务器上不应出现新训练进程。
5. 先在聊天说“查询 任务名称，展示配置，不要启动”，再在核对后明确说“启动 任务名称”。
6. 或手动创建运行记录，确认页面状态为“待启动”；核对参数和目标后点击启动。
7. 打开运行监控，观察状态、日志和已采集指标。创建成功、启动提交和训练完成的提示应不同。
8. 在可中断的测试运行上验证停止，确认状态最终由后端确认，界面不会只凭点击动作显示“已停止”。

### 4. 报告、建议和修改

1. 训练结束后，先确认采集完整性与输出实际发布状态。
2. 读取或更新事实报告，核对版本、参数、dataset/split、指标定义和范围提示。
3. 需要后台分析时，在“设置”启用分析/建议，确认相关 Worker 已运行。
4. 在“分析与建议”查看任务状态。failed/attention 的任务可以按原任务重试，不能当成训练失败。
5. 检查建议中的事实路径、代码行号、论文原文与局限；基于一条建议生成计划。
6. 对照 old/new 确认后应用到独立副本，检查实际 diff 与检查结果。没有点击应用之前不应修改源码。
7. 准备派生运行，此时仍不应训练；再次确认才启动派生运行。
8. 两边报告准备好后看结果对比；协议不一致时必须显示不可比较的原因。

### 5. 论文与手机

1. 上传一个文本 PDF，查看 ready/processing/failed，而不是只看上传成功提示。
2. 搜索该 PDF 中的具体术语，打开命中片段，核对物理页码、文本与前后片段。
3. 下载原件、重建索引、删除测试论文。索引重建与删除都有明确操作确认。
4. 用手机或浏览器设备模式检查底部导航、历史聊天抽屉、运行面板、表单、键盘输入与图表。
