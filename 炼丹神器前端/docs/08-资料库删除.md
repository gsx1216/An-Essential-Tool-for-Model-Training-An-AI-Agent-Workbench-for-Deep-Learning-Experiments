# 资料库删除

更新日期：2026-10-29。

## 怎么使用

进入“资料与建议 → 论文资料库”，每张资料卡片都有“删除”。也可以打开“查看正文与索引”，在详情中删除。确认框会明确告知删除范围和无法恢复。

只允许删除本人上传的资料。解析仍在进行时暂不允许删除，以免解析结果与删除操作冲突；解析完成或中断租约过期后可以删除。

## 实际删除哪些内容

- `papers`：资料标题、解析状态等元数据。
- `paper_files`：上传的 PDF 原始二进制。
- `paper_chunks`：正文分块，以及相应的全文检索索引项。

不是只在页面隐藏。后端复用现有 `DELETE /papers/{paper_id}`，在事务中校验登录用户的资料归属与解析状态，删除 papers 行；MySQL 的 ON DELETE CASCADE 自动删除原件与正文块。历史聊天、已生成建议以及保存的引用快照保留。

删除的数据库空间可以被 MySQL 后续写入复用，但磁盘上的数据库文件不一定马上变小。本功能不额外执行锁表或表空间重建。

## 模块与技术

`src/views/LibraryView.vue` 使用 Vue 3、Element Plus 和已有 Axios API 客户端。资料卡片与详情共用删除函数，确认后提交请求；成功后清除相关正文、搜索结果与筛选状态，再刷新列表。通过现有请求序号阻止迟到的读取结果重新显示已删除资料。

后端无需新增接口或表，复用 FastAPI 鉴权、PaperService、PaperRepository、mysql-connector-python 事务和 MySQL 外键级联删除。
