## 启动

如果后端已经在运行，就不要再启动第二份。否则在后端目录、你的 langchain 环境中，按后端原有启动方式运行 Uvicorn，例如项目入口为 `app.main:app` 时：

```powershell
cd E:\code\LangChian_New
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

另开一个 PowerShell 启动前端：

```powershell
cd C:\Users\gsx\Desktop\炼丹神器前端
pnpm install --frozen-lockfile
pnpm dev
```

浏览器打开终端打印的地址，默认为 `http://127.0.0.1:5173`。不要双击 `index.html` 或 `dist/index.html`，应用需要 HTTP 服务和 API 转发。

依赖需要 Node.js **24.15 或以上的 24 系列 / 更新兼容版本**，或满足 package.json 的 22 系列版本。项目锁定 pnpm 11.25.0。若系统没有 pnpm，可在已安装的 Node 环境下使用 `corepack pnpm`，或安装该版本 pnpm。

你的本机已经有 Codex 自带运行时时，也可以直接运行本目录的 `启动前端.ps1`；它只为当前进程补充运行时路径，不修改系统 PATH，也不下载软件。

## 第一次使用

1. 注册、登录你的账号。
2. 在“设置”保存自己的模型 API Key。页面只显示配置状态，不回显已保存的 Key。
3. 在“训练服务器”保存 IP、端口、用户名、认证方式、工作目录与真实主机指纹，点击“测试连接”。
4. 在“实验与训练”新建实验，定义实际使用的数据集、评测协议和指标。
5. 配置“对话训练任务”：从下拉框选择实验、服务器和后端登记入口，填写默认参数。保存配置不会启动训练。
6. 在聊天中先查询任务；明确说“启动 你的任务名称”时，后端 Agent 才能调用训练工具。也可以从实验创建运行，核对参数后手动确认启动。
7. 打开运行监控，查看持久化状态、指标、日志、报告、分析与建议。
8. 上传文本 PDF，在资料库检索、阅读带页码的片段，或在聊天中讨论论文。Skill 可按轮选择。

训练入口和允许参数来自部署者的 Runner 注册表。没有可选入口时，需要在后端配置登记脚本；前端不能任意执行 shell 命令。

## 常用命令

```powershell
pnpm check:api   # API 路径/方法对照后端 OpenAPI 快照
pnpm typecheck   # TypeScript 与 Vue 类型检查
pnpm test        # 前端回归测试
pnpm lint        # 代码问题检查
pnpm build       # 构建生产 dist/
pnpm api:types   # 后端快照更新后，重新生成接口类型
```

`pnpm preview` 只预览静态构建，不提供开发模式的 API 代理。需要联调时使用 `pnpm dev`；部署时使用 `deploy/nginx.conf` 的同源代理。

## 配置

默认浏览器请求 `/api/...`，开发服务器会去掉 `/api` 前缀再转发到 `http://127.0.0.1:8000`。后端真实路径仍是 `/auth/...`、`/sessions/...` 等。

如后端端口不同，可复制 `.env.example` 为 `.env.local`，修改：

```dotenv
VITE_API_BASE=/api
API_PROXY_TARGET=http://127.0.0.1:8000
```

改动代理目标后重启 `pnpm dev`。`VITE_` 变量会进入浏览器构建，只放公开地址，不能放 MySQL 密码、加密密钥、SSH 密钥或模型 API Key。登录和服务器凭据均通过对应后端接口保存。
